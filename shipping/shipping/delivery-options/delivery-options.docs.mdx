description: 'Standard, express and next-day delivery, priced from the shipping rate quote.'

`deliveryOptionsFor` prices the three ACME delivery services for a parcel: standard is the `rateQuote` for the weight and zone, express is 1.6 times that and next-day 2.4 times, rounded to whole cents. Orders of 10 items or more (`FREE_EXPRESS_MIN_ITEMS`) get express for free — pass `itemCount` to apply it. `DeliveryOptions` renders them as a radio group with a `PriceTag` per option and hands the full option, price included, to `onChange`.

## Pick a delivery service

```tsx
import { DeliveryOptions } from '@acme-modular/shipping.shipping.delivery-options';
import type { DeliveryOption } from '@acme-modular/shipping.shipping.delivery-options';

const [delivery, setDelivery] = useState<DeliveryOption>();

<DeliveryOptions weightKg={2 * itemCount} zone={1} itemCount={itemCount} value={delivery?.id} onChange={setDelivery} />
```

## Price without the UI

```ts
import { deliveryOptionsFor } from '@acme-modular/shipping.shipping.delivery-options';

deliveryOptionsFor(2, 0);
// [{ id: 'standard', cents: 790, ... }, { id: 'express', cents: 1264, ... }, { id: 'next-day', cents: 1896, ... }]
```

## Free express for large orders

```ts
deliveryOptionsFor(20, 0, 10);
// express is { id: 'express', cents: 0, ... }; standard and next-day are unchanged
```

## Uncontrolled

Leave `value` out and the component tracks the selection itself.

```tsx
<DeliveryOptions weightKg={6} zone={2} onChange={(option) => track('delivery-picked', option.id)} />
```
